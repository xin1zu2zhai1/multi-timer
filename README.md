# multi-timer

ブラウザで使えるシンプルなタイマーです。通常のカウントダウン、ポモドーロ・テクニック用のモード、ストップウォッチの3つのモードがあります。

**公開ページ：** https://xin1zu2zhai1.github.io/multi-timer/

HTMLファイル1つだけで動きます。外部ライブラリや音声ファイルは使っていません。

## 機能

### 通常モード

- 残り時間を「時:分:秒」で表示します。
- 時・分・秒の入力欄に直接時間を入力できます。
- プリセットボタン：**5分** / **10分** / **30分**
- 操作ボタン
  - **スタート / ストップ**：押すたびに開始と一時停止が切り替わります。
  - **クリア**：時間を 0 に戻します。
  - **セット**：入力欄の時間をタイマーに反映します。入力欄で Enter キーを押しても同じです。
- 時間になるとアラームが鳴り、数字が点滅します。数字をクリックするとアラームが止まります。

### ポモドーロ・モード

- **実行時間**、**休憩時間**、**長い休憩** をそれぞれ設定できます。
  - 実行時間のプリセット：**15分** / **25分** / **50分**
  - 休憩時間のプリセット：**5分** / **10分** / **15分**
  - 長い休憩のプリセット：**15分** / **20分** / **30分**
- 実行 → 休憩 の順に自動で進みます。
- **長い休憩**：「実行 ○ 回ごとに長い休憩」で指定した回数ごとに、通常の休憩の代わりに長い休憩が入ります（初期値は4回ごとに15分）。
  - 画面には「長い休憩まで 2/4」のように、今が何回目かが表示されます。
  - 回数を 0 にするか、長い休憩の時間を 0分にすると、長い休憩は入りません。
- **ループ**ボタン
  - **ON**：実行 → 休憩 を繰り返します。画面にサイクル数が表示されます。
  - **OFF**：1サイクル（実行 + 休憩）で終わります。
- フェーズが切り替わるとき、約1秒の短いアラームが鳴って自動で止まります。鳴っている間は `00:00:00` が表示されます。
  - 実行の終了（休憩へ）：「ピロリン♪」と上がっていく3音
  - 休憩・長い休憩の終了（実行へ）：「ポーン、ポーン」と低めの2音
- 操作ボタン：**スタート / ストップ** / **クリア** / **セット** / **ループ**

### ストップウォッチ

- 経過時間を「時:分:秒.1/100秒」で表示します。
- 操作ボタン
  - **スタート / ストップ**：押すたびに計測と一時停止が切り替わります。
  - **クリア**：経過時間とラップの記録を消します。
  - **ラップ**：計測中に押すと、その時点のラップタイム（前回からの時間）と合計時間を記録します。新しいラップが上に表示されます。
- 別のモードに切り替えると一時停止します。戻って「スタート」を押すと続きから計測します。

### デスクトップ通知（全モード共通）

- 画面下の **デスクトップ通知** ボタンで ON / OFF を切り替えます。初めて ON にするとき、ブラウザから通知の許可を求められます。
- 次のタイミングで通知が出ます。別のタブやアプリで作業していても気づけます。
  - 通常モードの終了
  - ポモドーロの「休憩に入ります」「長い休憩に入ります」「実行を開始します」「ポモドーロ終了」
- ON / OFF の設定はブラウザに保存され、次に開いたときも引き継がれます。
- 通知がブロックされている場合は、ブラウザのサイト設定で許可してください。
- パソコンのブラウザ向けの機能です。スマートフォンのブラウザでは通知が出ないことがあります。

## 使い方

1. 画面上部のタブで「通常モード」「ポモドーロ」「ストップウォッチ」のどれかを選びます。
2. 通常モード・ポモドーロでは、プリセットボタンを押すか、時間を入力して「セット」を押します。
3. 「スタート」を押すと計測が始まります。

> **注意：** ブラウザの仕様で、ページを一度も操作していない状態では音を鳴らせません。「スタート」ボタンを押した時点で音が使えるようになるので、通常の使い方では問題ありません。

## ローカルで使う

`index.html` をブラウザで開くだけで使えます。

デスクトップ通知は、GitHub Pages のような `https://` のページや `localhost` で使えます。ファイルを直接開いた場合は、ブラウザによっては通知が使えません。

## 動作環境

Chrome、Edge、Firefox、Safari の最新版（パソコン・スマートフォン）。ダークモードにも対応しています。
