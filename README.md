# multi-timer

ブラウザで使えるシンプルなタイマーです。通常のカウントダウンと、ポモドーロ・テクニック用のモードがあります。

**公開ページ：** https://xin1zu2zhai1.github.io/multi-timer/

HTMLファイル1つだけで動きます。外部ライブラリや音声ファイルは使っていません。

## 機能

### 通常モード

- 残り時間を「時:分:秒」で表示します。
- 時・分・秒の入力欄に直接時間を入力できます。
- プリセットボタン：**5分** / **10分** / **30分**
- 操作ボタン
  - **スタート / ストップ**：押すたびに開始と一時停止が切り替わります。
  - **クリア**：時間を 0 に戻します。
  - **セット**：入力欄の時間をタイマーに反映します。入力欄で Enter キーを押しても同じです。
- 時間になるとアラームが鳴り、数字が点滅します。数字をクリックするとアラームが止まります。

### ポモドーロ・モード

- **実行時間** と **休憩時間** をそれぞれ設定できます。
  - 実行時間のプリセット：**15分** / **25分** / **50分**
  - 休憩時間のプリセット：**5分** / **10分** / **15分**
- 実行 → 休憩 の順に自動で進みます。
- **ループ**ボタン
  - **ON**：実行 → 休憩 を繰り返します。画面にサイクル数が表示されます。
  - **OFF**：1サイクル（実行 + 休憩）で終わります。
- フェーズが切り替わるとき、約1秒の短いアラームが鳴って自動で止まります。鳴っている間は `00:00:00` が表示されます。
  - 実行の終了（休憩へ）：「ピロリン♪」と上がっていく3音
  - 休憩の終了（実行へ）：「ポーン、ポーン」と低めの2音
- 操作ボタン：**スタート / ストップ** / **クリア** / **セット** / **ループ**

## 使い方

1. 画面上部のタブで「通常モード」か「ポモドーロ・モード」を選びます。
2. プリセットボタンを押すか、時間を入力して「セット」を押します。
3. 「スタート」を押すとカウントダウンが始まります。

> **注意：** ブラウザの仕様で、ページを一度も操作していない状態では音を鳴らせません。「スタート」ボタンを押した時点で音が使えるようになるので、通常の使い方では問題ありません。

## ローカルで使う

`index.html` をブラウザで開くだけで使えます。

## 動作環境

Chrome、Edge、Firefox、Safari の最新版（パソコン・スマートフォン）。ダークモードにも対応しています。
